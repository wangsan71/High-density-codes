# PSKT v5 · 重规划（**已批准**）：纸面密度最大化 · 图像优先 · 取消 3D 板材线

> **状态**：产品负责人在第 109 轮批准。本文档**取代** `docs/PLAN.md`（v3）里与 3D 板材/喷嘴相关的部分，
> 并**改变产品口径**（从"文件传输"改成"**图片优先、纸面密度优先**"）。
> **不动**的是：判决权威仍是 `docs/ACCEPTANCE.md`；台账纪律仍是 `AGENTS.md` §6；
> 硬性约束（零依赖、纯 ESM 双宿主、**绝不输出"看起来成功但是错"的数据**）一字未改。
> **执行方式**：静默——只在 ① 需要用户动手（打印/扫描/浏览器）② 严重错误 ③ 需要拍板 三种情况出声。

---

## 1. 目标（可测）

**一句话**：在**尽可能小的纸上**印**尽可能小的模块**，装**尽可能多的数据**；**先做图片**，文件后置。

| 指标 | 定义 | 基线（今天） |
|---|---|---|
| **面积密度** | 净字节 ÷ 码区面积（B/mm²） | 已验证最高 **0.83 B/mm²**（`P-MX-300-4`：44.4 KB ÷ 191.3×278.6 mm）≈ **QR 码同级**（QR v40-L：2953 B ÷ 58×58 mm ≈ 0.88 B/mm²） |
| **纸尺寸阶梯** | 同一载荷能印到多小的纸 | 今天只有 A4（`--sheet` 收 `A4` 或 `Letter`） |
| **页数** | 同一载荷的页数 | 1 MB 不可压：旧默认档 169 页；密档 **29 页**（模拟实测） |

**"同一载荷（44.4 KB）逐步缩纸"所需的模块间距**（码区 = 纸张减边距）：

| 纸 | 码区 | 所需间距 | 打印/扫描 dpi | 状态 |
|---|---|---|---|---|
| A4 | 191×279 mm | 0.339 mm | 300 | ✅ 已模拟 16/16 |
| **A5** | ≈130×192 mm | **0.23 mm** | 300（2.8 px）/ 600（4.7 px） | 待测 |
| **2R** | ≈55×80 mm | **0.10 mm** | 600（2.4 px）/ 1200（4.7 px） | 待测，**物理上很可疑** |

**提高密度的四条杠杆**（P0 一次全测，不预设结论）：① 更小间距（受渗展 + 扫描 MTF 限制）② 更高 dpi ③ 每模块多比特（4 级灰）④ 彩色多通道。

## 2. 起点（事实，不许当"应该没问题"）

- 协议主链可用且不动：RS/GF(256)、CRC16、SHA-256、ChaCha20、自研 deflate、帧头/会话/交织、`TransferAssembler`、单应校正、回显条。
- 稠密模块档已落地（`P-MX-300-6/5/4` = 20.1 / 29.1 / **44.4 KB/页**），**模拟平板扫描 16/16 逐字节还原**，真机未验。
- 纸面尺寸只支持 A4/Letter；`sheetPlacement(contentMm, sheetMm)` 吃任意 mm ⇒ 加 A5/2R 是接线工作。
- 小载荷恒 3 页（`parity = max(2, 20%)`）——独立于密度的一处浪费。
- 手机路径今天 **0/8**（要求整页四角入画）⇒ 纸越小越不可能 ⇒ **瓦片化（QR 式）是必需项**。
- **所有**模块档目前只有模拟证据；真打印机 + 真扫描仪一次都没量过。

## 4. 判据（可判红绿）

| 编号 | 判据 |
|---|---|
| **G-CAP** | 面积密度 ↔ 模块间距的**实测表**（P0 产出）为唯一依据；`send --dry-run` 报的页数 = 实际页数；容量表与实测偏差 ≤10% |
| **S-LADDER** | 同一载荷在 A4 / A5 / 2R 各印一次、各扫一次：成功率 ≥99%（每档 20 seed 仿真 + 真机 1 张） |
| **G-IMG** | ≤1 MB 图片：`--pages N` 模式下 ≤N 页；重建图 **PSNR ≥ 30 dB**；`fit` 模式**必须**在产物/manifest/UI 三处标注有损；`exact` 仍逐字节相同 |
| **G-TILE** | 瓦片路径：局部入画（≥60% 面积或单瓦片）即可出数据；缺瓦片由 RS 重建；**误接受仍为 0** |
| **G4′** | 原「四角标必须都在画面内」前提**作废**，改为「任意瓦片入画即可读 + 失败分类 + 重拍建议」（产品负责人已批准改口径） |

## 5. 阶段

### P0 · 密度阶梯测量（进行中）
- `tools/density-ladder.mjs`（**已落地**）：`--make` 在现有版面上画多条已知伪随机比特带（0.847 → 0.085 mm）+ 真尺寸 PDF；`--read` 登记后逐带给 BER / 净 B per page / bit per mm² / 可用性，带内 ±4 px 对齐搜索。
- **未完成**：① 3 px / 2 px 带在**原始渲染**上仍有 4.7e-4–1.4e-3 本底误码 = 尺子自身的配准/重采样噪声 ⇒ 读数改走解码器的 timing 行校准 + 亚像素配准；② 真机数字（用户打印 1 张 + 扫 300/600/1200 dpi）。
- **退出条件**：一张实测容量表写进本文档 §6；明确 0.17 / 0.13 / 0.10 mm 在该用户机器上是否可读。

### P1 · 档位与页数策略
按 P0 结果新增/选定 `P-MX-{dpi}-{px}` 系列（含多级灰，若实测支持）；图片默认走**最密的可靠档**；小载荷页数下限修正（≤2 数据页时允许 0–1 校验页，产物明写「1 页 · 无冗余」）；`pskit status`/`USE.md`/验收包同步。

### P2 · 纸尺寸阶梯 A4 → A5 → 2R
`--sheet A4|A5|2R|<WxH mm>`；同一载荷三档打印/扫描；边距与裁切标记按新尺寸重算。

### P3 · 图片管线（用户指定"先做图片"）
`--image-mode exact|fit` + `--pages N`：`fit` = 等比降采样（必要时再上自研有损编码）把图塞进 N 页；**有损必须显式标注**，摘要算在实际传输的图片字节上，原文件 sha256 只作参考。先做 `fit v1 = 降采样 + PNG`，按实测曲线决定是否上 `v2 = 自研 baseline JPEG`。

### P4 · QR 式瓦片码 + 手机扫码
每页 = M×N 个自带定位图形的瓦片（QR 同款三实心 + 一空心），瓦片级 RS；新增 `core/decode/tile-read.js`；手机接收页改成「对准任意一个瓦片即收」。

### P5 · 文件（后置）
现有文件路径保持可用；等图片路径稳定后再让文件享受同样的密度与瓦片。

## 7. 需要用户做的（P0，等尺子本底修好后再叫他做）

1. 打印阶梯页（**100% 缩放**，别选"适应页面"）→ 用 **300 / 600 dpi** 各扫一次（彩色、关自动裁剪、存 PNG 或 TIFF）→ 放进一个目录 → 跑一条命令 → 把输出发回。
2. 支持 1200 dpi 的话再加一次（0.10 mm 那档靠它）。
3. 三个不阻塞的决定：最终最小纸张是不是 2R？**是否允许灰阶/彩色**（提密但降抗损）？**是否接受有损图片模式**（无损模式仍保留）？

## 8. 风险与不承诺

| 风险 | 依据 | 应对 |
|---|---|---|
| 0.10–0.13 mm 真机读不出 | 渗展 0.05–0.15 mm + 扫描 MTF | P0 先测；不达标就**如实把目标改成实测值** |
| 灰阶/彩色不可靠 | 无数据 | P0 同测；不可靠就不上线（不放宽判据） |
| 手机读小纸 | 今天整页 0/8 | P4 瓦片；瓦片尺寸由 P0 定 |
| 真机证据缺 | 全是模拟 | P0 阶梯页就是第一次真机测量 |
| 3D 线退役后 G7/G8/G10 成孤儿 | — | 划线保留 + 说明；代码冻结不删 |

## 9. 一句话

**把 3D 板材整条线冻结，专注"在越来越小的纸上（A4 → A5 → 2R）装越来越多的数据"**；以 P0 的真机测量为唯一依据；图片优先；手机靠 QR 式瓦片；全程静默，只在需要你动手、严重错误、要你拍板时出声。
