## 0. 目标

一条不依赖任何外部源（无网络、无 URL、无云服务）的数据传输链路：

```
文件 → 自研高密度码 → (A) 纸面页 PNG/TIFF/最小PDF
                      → (B) 3D 板材 3MF/STL（双色优先，单色可还原）
     → 手机拍摄 / 平板扫描 → 浏览器(GitHub Pages) 或 CLI 解码 → 逐字节还原
```

核心不变式：**解码器宁可失败，也绝不产出错数据**（页级 CRC16 + 载荷摘要双闸 + 原子落盘）。

## 1. 版本决策（相对早期草案）

1. **产物是可被切片器读取显示的模型文件**：3MF（底板 + 色A/色B 两个**合并岛**部件 + `<basematerials>` 自动分料）+ 二进制 STL（单色）。不产出 G-code。
2. **双色优先、单色兜底是协议级保证**：色道 = 数据位，形道（形状/纹理）= RS 校验位。色道整体塌陷 = 整段擦除，擦除纠正强度是纠错的 2 倍 → G7 强制"颜色全丢也 100% 还原"。
3. **扫描端 = GitHub Pages 静态 PWA**：纯前端、零上传、CSP `default-src 'self'`、SW 离线预缓存、`?selftest=1`。`getUserMedia` 仅 https 可用 → 另出单文件 `index.html`（`file://` 可开，走"选照片/拖文件"）+ 本地 `python -m http.server` 后备。
4. **零依赖纯 ESM JavaScript 单一核心**：Node CLI 与浏览器共用同一份源码（无 npm install / vite / tsc / OpenCV.js）。Python 3.10 + numpy + opencv-python 仅用于仿真信道、独立参考解码、3MF/STL 第三方解析校验。
5. **喷嘴档位化 + 喷嘴无关判决 + 通用保底档**（见 §3）。

物理事实：0.8 喷嘴最小可靠特征 ≈ 2.4mm，是 0.2 喷嘴（0.6mm）的 1/16 面积分辨率。"一张板通吃所有喷嘴且保持容量"不成立 → 用三条机制替代：喷嘴档位、比值型判决、`PL-G` 保底 + `calibrate` 实测选档。

## 2. 通道矩阵与档位

每格 cell 有物理独立的可读通道：

| 通道 | 物理载体 | 喷嘴敏感性 | 承载 |
|---|---|---|---|
| 色道 C | 整格换料（料1/料2/4料） | 低（选哪卷料，与线宽无关） | **数据位** |
| 形道 S | 格内形状（圆盘/方环/十字/点）+ 顶面纹理（实心 vs 镂空肋） | 高 | **校验位**、低优先级位 |
| 高道 H | 0.2mm 凸起（光影还原，`REL` 档） | 中 | 可选第三通道 |

| 档位 | 载体 | bit/格 | 单色 | 双色 | 说明 |
|---|---|---|---|---|---|
| `P-M1` | 纸面 300/600dpi | 1 | ✔ 原生 | ✔ | 主推纸面 |
| `P-M2` | 纸面 600dpi | 2 | ✔ | ✔ | 高密度纸面 |
| `P-C4` | 纸面 600dpi 4色 | 2+ | — | ✔ | 可选 |
| `PL-M1` | 板材纯色 | 1（形状） | ✔ 原生 | ✔ | 3D 单色 |
| `PL-D2` | 板材双色 | 2 = 色数据+形校验 | ✔ **降级可还原** | ✔ 最优 | 3D 主推 |
| `PL-D3` | 板材 4 料 | 3 = 2bit色+1bit校验 | ✔ 降级 | ✔ | 4 槽 AMS |
| `PL-G` | 板材 2.4mm 宏格 | 1，1/2 码率 | ✔ | ✔ | **任何喷嘴/参数/手机必可读** |
| `REL` | 板材仅高度差 | 1（光影） | ✔ | ✔ | 拉伸档 M10 |

## 3. 喷嘴自适应（v3 核心）

| nozzle | 标称挤出宽 | 最小格距 | 可用 glyph | 200×200 板格数 |
|---|---|---|---|---|
| 0.2 | 0.22–0.30mm | **0.60mm** | 圆盘/方环/十字/点 | 333² |
| **0.4（默认）** | 0.42–0.55mm | **1.20mm** | 圆盘/方环/十字 | 166² |
| 0.6 | 0.65–0.80mm | **1.80mm** | 圆盘/方环 | 111² |
| 0.8 | 0.85–1.10mm | **2.40mm** | 圆盘/环（十字会糊，剔除） | 83² |

机制：

1. `--nozzle 0.2|0.4|0.6|0.8`（默认 0.4）→ 选最小格距与 glyph 集。
2. **挤出宽度整数倍量化**：格距、环宽、中心尺寸一律 `round(k × EW)`，消除格内走线随机错位对面积比的污染。
3. **比值型 glyph（喷嘴不变判决）**：每格 = 外圈参考环（永远打印）+ 中心特征；判决量 `ρ = 中心实心面积 / 环实心面积`。喷嘴变粗时两者同比膨胀 → ρ 近似不变；再用页内校准带做局部归一化，使喷嘴宽度、点增益、层高、顶面皮肤策略、曝光漂移从判决中消去。
4. **`--nozzle auto` + `pskit calibrate`**：先打喷嘴无关 **MTF 校准板**（0.6/0.9/1.2/1.8/2.4mm 阶梯格 + 双色样本 + 纹理样本 + 标尺），拍回 → 实测稳定最小格距、色道分离度、白平衡漂移 → 输出建议档并据此出正式板。
5. **码流按"喷嘴不敏感优先"填入通道**：先填色道，再填形道 → 喷嘴变差时丢的是校验位而非数据位。

## 4. 协议 PSKT-1

发送管线：

```
文件 →[可选 ChaCha20(PBKDF2-SHA256 口令)]→ 自研 DEFLATE 压缩(不可压则 store)
     → SHA-256 摘要 → 分页 → 页间 RS 擦除码(10/20/33%) → 页内 RS(255,223)+对角交织
     → 按通道路由(色道=数据 / 形道=校验) → 版面渲染
```

- **两级纠错**：页内 RS(255,223)（16 校验符号/块，numpy-free JS 实现）；页间把同一字节偏移跨 k 个数据页构成 RS(n=k+p) 码字 → 允许缺页/乱序/重复拍摄。
- **帧头 40B（CRC16）**：magic `PSK1` / 版本 / 档 id / 喷嘴档 / 码率 / **会话 id(8B)** / 页序(16b) / 总页(16b) / 校验页数(8b) / 总字节长(32b) / 载荷摘要(32B)。页边距放 **2 份大格回显副本**（半页也能认出缺哪一页）。
- **几何**：四角同心方环 fiducial + 左上唯一朝向标记（旋转/镜像判定）+ 四边双频**对齐梳**（相位相关亚像素格点相位）+ 边缘保护环（环内格子一律标擦除）。
- **判决**：每格输出软置信度（ρ 面积比 + 角点矩 + 环向填充曲线；色道用白平衡后 LAB 距离），低于阈转擦除喂 RS。

容量预算（`G-CAP` 断言取表中值 80% 为下限，验收时改为实测）：

| 档 | 格距 | 幅面 | 格数 | 原始 | 净/单元 | 1MB 需要 |
|---|---|---|---|---|---|---|
| `P-M1@300dpi` | 0.85mm | A4 200×280mm | 77k | 9.7KB | 6.8KB/页 | ~150 页 |
| `P-M1@600dpi` | 0.42mm | 同上 | 308k | 38KB | 27KB/页 | ~38 页 |
| `P-M2@600dpi` | 0.42mm 2bit | 同上 | 308k | 77KB | 38KB/页 | ~27 页 |
| `PL-N02` 双色板 | 0.60mm | 200×200mm | 111k | 27KB | ≈9.6KB/板（单色兜底≈4.8KB） | ~105 板 |
| `PL-N04` 默认 | 1.20mm | 200×200 | 27.6k | 6.9KB | ≈2.4KB/板（单色≈1.2KB） | — |
| `PL-N06` | 1.80mm | 200×200 | 12.3k | 2.5KB | 0.9KB/板 | — |
| `PL-N08` | 2.40mm | 200×200 | 6.9k | 1.4KB | 0.5KB/板 | — |

## 5. 自动门限 G0–G10

| Gate | 判据 |
|---|---|
| G0 | GF(256)/RS 已知向量+随机属性、ChaCha20 RFC 8439、SHA-256/HMAC/PBKDF2 向量、CRC16/32、位打包 Gray、帧编解码、压缩往返 |
| G1 | 像素级理想往返 0 符号错；≥5 类载荷 + STL 模型往返（模型→码→还原→逐字节相同） |
| G2 | 纸面 300/600dpi × 200 固定 seed × ≤1MB → 100% 字节相同；ECC 前 BER < 1e-5 |
| G3 | 缺页/乱序/重复：擦除 ≤ 校验数 100% 恢复；超出干净拒绝（原子写，绝不产部分文件） |
| G4 | 手机压力档（35°/失焦/运动模糊/JPEG45/指头遮挡/卷曲/暗光/裁切）各 500 seed ≥99%，失败均有分类 + 重拍建议 |
| G5 | 误接受实测 0：1 万次随机篡改全拒；变异测试证明套件自身能抓错 |
| G6 | 编码 1MB ≤5s、解码 ≤2s/页；30–60 分钟 soak（后台任务）RSS 增长 ≤10%、零误接受 |
| G7 | 单色兜底：`PL-D2/D3` 色道完全塌陷下 100% 还原 + 双色/单色同板净载荷对比表 |
| G8 | 模型可导入：Python 独立解析 3MF（schema、部件数=底板+色A+色B、`basematerials`↔料号、网格水密=每边恰 2 三角形、法线一致、包围盒）与 STL（50+50N、三角数、包围盒） |
| G9 | Web/Pages：`web/dist` 零第三方 origin（grep+CSP 断言）、SW 清单哈希与产物一致、`?selftest=1` 全绿、`file://` 单文件"选照片→解码"可跑、无 https 时相机模式明确降级提示 |
| G10 | 喷嘴×参数×拍摄条件矩阵：`PL-G` 在全部喷嘴与全部扰动组合下 100%（保底不变式）；`PL-Nxx` 标称喷嘴 100%、相邻喷嘴 ≥99% 或给出具体重打提示；纸面档在 300/600dpi 两类打印机同样成立 |

## 6. 其他失败因素清单与对策（每条须有仿真档 + G10 用例）

| 因素 | 对策 | 仿真档 |
|---|---|---|
| 喷嘴宽度/挤出宽差异 | 挤出宽整数倍量化 + ρ 比值判决 | 4 喷嘴 × EW±20% |
| 层高/顶层数/切片器皮肤策略 | 语义全由几何表达 | 层高 0.1/0.2/0.3、顶层 1/3 |
| 点增益、打印机 MTF 差异 | 校准带 + `calibrate` 实测选档 | MTF 阶梯 + 形态学膨胀 |
| 换料 purge 泄漏 / 岛间串色 | 岛间隔离缝 + 色道门限自适应 + 校准带样本探测 | 串色 ±20%、打印顺序 A→B/交替 |
| 缺料/只装 1 卷料却打 D 档 | 形道校验恢复 | 色道完全塌陷档 |
| 板面（PEI 光面/纹面/玻璃）反光 | 顶面 2–3 层 + 建议哑光面 + 局部阈值 | 高光削顶、镜面渐变 |
| 翘边/卷曲、Z 条纹与共振 | 采样窗 ±3px 局部搜索 + 逐行置信度 | 翘边单应 + 周期条纹 |
| 自动曝光/白平衡漂移 | 白平衡校正 + ρ 比值 + 校准带定阈 | 2500K/5000K/荧光 + 曝光 ±1.5EV |
| 镜头畸变、距离/角度、景深 | 朝向标记 + 对齐梳 + UI 建议 2× 变焦/40cm | 0/20/35°、25/40/60cm、失焦、运动模糊 |
| 支撑痕迹/底面过曝 | 码面朝上、只用顶面 | 底面污染档 |
| 混拍两批 / 重复拍 / 乱序 | 会话 id 过滤 + 页序 CRC 去重 | 混合语料档 |
| 半页入镜 | 回显帧头指出缺哪部分 | 局部裁切档 |
| 误接受 | CRC16 + SHA-256 双闸 + 原子写 | 1 万次篡改全拒 |

## 8. 里程碑

M0 骨架 → M1 编码核心(G0) → M2 渲染器+校准板(G1) → M3 解码器(G1,G2) → M4 仿真信道+验收套件(G2–G5) → M5 3D 产物(G8) → M6 双色/单色双效(G7) → M7 喷嘴矩阵+PL-G+calibrate(G10) → M8 Web 扫描端(G9) → M9 长跑加固+文档(G6 + 复跑) → M10 可选 `REL`/`P-C4`。

每步：实现 → 跑对应门限 → git commit + tag → 更新 `docs/STATUS.md`。

## 9. 自验收与长时运行

- **双实现交叉**：`core/`(JS) 与 `ref/`(Python) 对同一 `tests/conformance.json` 语料必须逐字节一致。
- **G8 第三方解析**：Python 原生 `zipfile`/`struct` 校验模型文件，替代"人眼看切片器"。
- **`docs/STATUS.md` 台账**：里程碑 × 门限 × 最近实测值；跨轮/重启可确定性续跑。
- **soak 走后台任务**，不阻塞其他步骤。

## 10. 假设

1. 不引入 npm 依赖；若确需 devDep 用 `--cache ./.npm-cache` 并先征求批准。
2. GitHub Pages 的推送与开关由用户执行；本地用 `python -m http.server` + `tools/check-dist.mjs` 等价验证。
3. 真机打印/扫描属 M9 之后的人工验收（SOP 与 `calibrate` 已备好）；本轮"成功"以仿真门限 + 双实现交叉为准。
4. 3D 档默认 0.4mm 喷嘴 / 200×200mm 板 / 顶面朝上无支撑；双色按 AMS/MMU 类多料机设计。
5. 自研 ChaCha20 过 RFC 8439 向量，但不宣称等同经审计实现。
