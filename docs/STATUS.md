## 决策与已知风险

- 零依赖：Node 24 + 浏览器原生 ESM，无构建步骤（npm CLI 在本机沙箱不可写缓存目录）。
- 摘要用 SHA-256（自研纯 JS，`crypto.subtle` 在 `file://` 非安全上下文不可用）。
- 压缩用自研 DEFLATE 子集（LZ77 + 固定 Huffman + stored 回退），跨宿主同步。
- 页间 RS 要求 **总页 ≤ 255**、各页符号数相同（版面固定 → 天然满足，尾部 pad）。
- 容量诚实结论：3D 板材为 KB 级，MB 级走 600dpi 纸面。
